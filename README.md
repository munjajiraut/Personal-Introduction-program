# Personal Introduction Program

## Project Overview
A simple Python program that asks the user for their name, age and
hobby, then displays a friendly welcome message.

## Setup Instructions
1. Install Python from python.org
2. Download this project folder
3. Open Command Prompt in the folder
4. Run: python personal_intro.py

## What I Learned
- Using input() to take user input
- Storing answers in variables
- Using f-strings with print()
- Running Python programs from the terminal
